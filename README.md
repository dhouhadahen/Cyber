Présentation
Cette application interactive (SPA) a été développée pour présenter le diagnostic de cybersécurité et les protocoles de gestion de crise à la direction de l'EHPAD Les 7 Fontaines. Conçue avec une approche institutionnelle et clinique, elle vise à faciliter la prise de décision stratégique face aux risques numériques en milieu de santé.

Cybersecurity Report & Dashboard — EHPAD Les 7 Fontaines
Overview
This interactive Single-Page Application (SPA) was developed to present cybersecurity diagnostics and crisis management protocols to the executive management of the Les 7 Fontaines nursing home (EHPAD). Designed with a clinical and institutional approach, it aims to facilitate strategic decision-making regarding digital risks in a healthcare environment.

Key Features
Crisis Sequencer: Interactive tool simulating the priority actions required within the first 30 minutes of a confirmed cyberattack.

Care Continuity Plan: Mapping of backup procedures for degraded mode operations (without IT system access).

Robustness Assessment: Audit of backup strategies according to the institutional 3-2-1 rule.

Installation and Setup (Local)
Bash
# Install dependencies
npm install

# Run the development server
npm run dev
